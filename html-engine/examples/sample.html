html-engine sample

The HTML deck engine

Agent writes HTML/CSS. Workpod renders it live. Same source ships to PPTX and PDF without a translation step.

Why it's better

WYSIWYG instead of translation

  • Agent writes HTML/CSS; rendered output is the source of truth
  • No padding/font/overlap surprises from pandoc geometry
  • Themes are CSS variables — way more powerful than reference.pptx surgery
  • Editable PPTX via DOM-walking export: each visual is a real shape
